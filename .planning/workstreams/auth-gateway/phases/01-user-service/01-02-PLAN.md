    1. AUTH-03: signup으로 발급받은 refresh를 POST /v1/auth/refresh로 제출 → 200 + 새 accessToken, 응답 refreshToken=null(미회전, D-P1-1 확인). 새 access를 jjwt로 파싱해 subject 일치 검증.
    2. AUTH-03: 조작/미존재 refresh 문자열 → 401(InvalidToken). (만료 케이스는 만료 refresh 행을 DB에 직접 심거나 AuthServiceTest 단위로 커버 — 이식본에 이미 존재하면 통합 중복 생략.)

    4. AUTH-04: 로그아웃에 사용된 refresh로 다시 POST /v1/auth/refresh → 401(삭제되어 갱신 불가). AUTH-04 무효화의 최종 관측.
