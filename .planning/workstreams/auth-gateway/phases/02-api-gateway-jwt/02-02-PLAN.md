## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client → gateway :8000 | 미인증 외부 입력. 위조 X-User-* 헤더 + 누락/무효/만료 토큰이 여기서 차단되어야 함 |
| gateway → downstream (공개/인증 경로) | 공개 경로도 strip 후 통과 — downstream이 클라 위조 헤더를 받지 않아야 함 |

| T-02-02 | Spoofing | 401 단락 (GATE-03) | high | mitigate | 누락/무효/만료 → downstream 무호출 401. Task 2(a) 3종이 downstream 미도달을 assert |
| T-02-03 | Spoofing | 만료 토큰 재사용 | high | mitigate | jjwt parseSignedClaims가 만료 자동 거부 → 401(TOKEN_EXPIRED). Task 2(a)·Task 3(a) 검증 |
