<objective>
RESIL-03: ProcessingRecovery 를 멀티 인스턴스 스케줄러 동시 실행에 안전하게 만든다.
`pg_retry_count` 를 객체 mutation+save 가 아닌 **DB 원자 UPDATE** 로 교정해 카운터
유실을 없앤다. Testcontainers 동시 실행 테스트로 검증한다.

Purpose: 스케줄러 Redis 분산락 만료/겹침 시에도 카운터 유실 0 보장. read-modify-write 경쟁 제거 (D-04 — 레코드 락은 YAGNI, 원자 UPDATE 만).
Output: incrementPgRetryCount 원자 UPDATE 배선 + retryPgCancel 교정 + 동시성 IT.
</objective>
