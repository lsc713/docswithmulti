1. 취소 시퀀스 — 3 코어 TX + 이력 1 배치 = 커밋 4

TX 경계(코어 3개)는 외부 호출(risk·PG)로 분리돼 병합 불가. 이력은 코어 TX 밖(감사 불변식). 실측으로 커밋 6→4 감축(이력 3커밋 → 1 배치) → 처리량 147→220 rps.

커밋 6 → 4: 이력을 상태전이마다 별도 커밋(3개)하던 것을, 전이 시각을 메모리에 캡처해뒀다가 cancel() 종료 시 1 트랜잭션으로 일괄 INSERT. 이력 3건·전이 시각 보존, 감사 불변식(코어 TX 밖·best-effort) 유지. 커밋(fsync)이 2코어 DB의 병목이라, 6→4 = 처리량 ×1.5.
