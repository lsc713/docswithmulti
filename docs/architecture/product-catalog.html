product-catalog v1.0 (2026-07-31, PR #83) · product-service :8084 · Flyway V3(category)·V4(product.category_id) · 풀 카탈로그 백필(경로 Y)의 첫 수직 슬라이스

▸ ← 아키텍처 개요 · 서비스별 메서드 흐름 →

v3.0에서 재고에 필요한 최소 카탈로그(product/sku/stock)만 있던 product-service에 카테고리(대·중·소) 계층 + 카테고리별 브라우징을 얹은 슬라이스. 재고 예약·복원 경로는 불변(INV-01) — 조회는 product_stock read-only join만 사용.

1. 데이터 모델

초록 이번 슬라이스 신규 · 파랑 기존(v3.0 재고) · 노랑 재고 상태(쓰기 경로 = 예약·복원, 불변). 실선 = FK.
